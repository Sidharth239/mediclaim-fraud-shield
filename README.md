# MediClaim Fraud Shield — Full Stack Web App

## Quick Start (3 steps)

1. pip install -r requirements.txt
2. python app.py
3. Open http://localhost:5000

## Features
- Dashboard: live charts, KPIs, Monte Carlo simulation
- Predict Claim: enter claim details → instant fraud probability
- Batch Upload: upload CSV → analyze all claims
- Claims Table: search/filter 15,000 claims
- Models page: ROC, confusion matrix, feature importances
- Retrain button: regenerates and retrains everything
